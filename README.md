# Linha do Tempo dos Desenhos Animados da TV

## Descrição do Tema
Um site interativo e informativo que apresenta a história dos desenhos animados da televisão em ordem de épocas, trazendo um texto descrevendo os tipos e formas mais comuns de desenho e uma seleção dos melhores desenhos de cada período.
